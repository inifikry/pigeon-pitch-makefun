# Pigeon Pitch, One Line

Entry for the make.fun bounty **Pigeon Pitch, One Line** (`u-donrulezz-pigeon-pitch-one-line-af06c6cf`).

## The bounty

Write the one-line elevator pitch a city pigeon gives investors for its startup. One line, at most 200 characters, in English. Entries are judged in blind rounds by a judge model that compares two pitches at a time: on subject first, then which is funnier, then originality, the pigeon's voice and city life, and how tightly the line is written.

## Final entry

> I run the city's original drone network: 10,000 pilots, paid in breadcrumbs, zero charging time — and we already poop on every statue downtown, so the brand awareness is built in.

## How to run

```sh
python3 main.py
```

Writes the pitch to `/output/entry.txt`. Deterministic: every run writes the exact same line.
